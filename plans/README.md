# Emperor Native 可玩化实施计划

由 `improve` 审计流程于 2026-07-22 生成。当前工作区没有 `.git`
元数据，因此各计划以 `plans/baseline.sha256` 和计划内的代码摘录做漂移检查。

这一组计划只承诺一个垂直切片：玩家从原版夏朝教程进入第一关
“Shelter and Sustenance”，不使用调试按钮或测试状态注入，能够建造、等待人口迁入、
形成肉食供应链、把至少 150 人的住宅提升到目标等级，得到明确胜利；也能够因连续
36 个月负债而失败，并可保存、载入或重玩。

## 依赖说明

- 001 先把“每 0.5 秒结算一个月”改成可保存、可重放的日/tick 时钟；后续计划都以
  它的月末边界和自然迁入为基础。
- 002 只覆盖教程第一关明确介绍的建筑和供给链，避免在垂直切片完成前扩散到全建筑表。
- 003 依赖真实 tick 驱动动画，也依赖 002 确定第一关必须出现的建筑和人物集合。
- 004 依赖 001 的月末边界来准确累计 36 个月负债，也依赖 002 的实际劳工人数结算工资。
- 005 最后执行；它是前四项的验收门禁，不应通过直接调用 `admitResidents`、写库存、
  指定满员工或构造目标快照来“完成”任务。

## 共同边界

- 原版安装始终只读，不修改、不复制进发行包。
- 本轮不覆盖后续夏朝关卡、其余 43 个官方单人任务、12 个网络场景、完整帝国外交、
  战略征服或全建筑/全人物素材。
- 不把“能启动”“可确定性空跑”“测试直接写入满足目标的快照”视为可玩。
- `advanceMonth(rules:)` 可以保留为兼容测试 API，但必须通过真实 tick 跑到月末，不能保留
  第二条独立规则路径。

## 已考虑但本轮延后

- **完整外交、英雄和军事重制**：价值高，但不是教程第一关通关依赖；垂直切片稳定后另立计划。
- **12 个网络任务**：需要大厅、同步和多人胜负协议，不能混入单人可玩化路径。
- **全 269 建筑和所有人物素材**：先覆盖教程第一关可见集合；全量展开会让验收失焦。
- **Developer ID、公证与商店发行**：当前本地打包已经存在，不解决“游戏不好玩”的核心问题。
