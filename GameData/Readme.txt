II. GENERAL TECHNICAL ISSUES
-----------------------------

Installation problems:
If you are having problems installing the game, first make sure that the hard drive you're installing to has sufficient free space.  Deleting the contents of your TEMP folder will help as well.  It is also recommended to disable any kind of Anti-Virus or Crash Guard programs that may be running in the background of Windows.

Users installing on Windows 2000 or Windows XP systems should have administrator access.

Sound issues:
Problems with stuttering sound have been reported on the Diamond Monster Sound MX400 sound card.  For any sound issues, we first recommend updating your sound card drivers. This is especially pertinent if you recently upgraded your version of DirectX. For good measure, update your video drivers as well (Emperor uses DirectSound, which is part of Microsoft's DirectX.) Reinstall DirectX, either from your EmperorRotMK CD or from Microsoft's website.  On Windows 98/ME be sure to close all programs other than Explorer & Systray (especially any MP3 players such as Winamp or Realplayer) before starting the game.

Windowed screen mode:
If you wish to run the game in a window, you must have your desktop set to at least one notch higher than your desired game resolution.  For example, if you wish to run the game in 800x600 windowed mode, your desktop will need to be set to 1024x768 or higher.  For 1024x768 windowed mode, the minimum desktop resolution setting is 1152x864.  It is also recommened to set your desktop color depth to 16-bit.  A desktop color depth setting higher than 16-bit color will result in performance loss.

Athlon Processors and Windows XP:  
We have seen degraded performance of Emperor on Windows XP systems with Athlon processors.  We recommend running in full-screen mode, preferably at 800x600 resolution, to boost game performance on those systems.


III. GENERAL GAME ISSUES
-------------------------

"Maximum Building Capacity Reached":
Emperor has limits on how many buildings, walkers and walker routes it can handle.  Though these limits are quite high, you might reach them if you build a city of 8,000 or more people.  If you do see this message, your only recourse is to resculpt your city for greater efficiency.  Even higher populations are possible if you build very efficiently.

Game speed in single player:
Occasionally, after playing Emperor in a multiplayer session and then starting a single player session, the game speed will reset to 0 percent.  Press the ] key to increase game speed in your single player session.

Ctrl and Alt keys:
Sometimes, if you have pressed the Ctrl or Alt keys while in play, the game will pause. Simply press the Ctrl or Alt key again to continue. This is not a substitute for the hotkey P to pause the game!

Turning intro movie off:
To set the Intro Movie so it doesn't play every time you load the program, locate Emperor.ini in your game directory, open it in Notepad, and change the line that reads PlayIntroMovie=yes to PlayIntroMovie=no.

Tip for building Great Wall:
Place your laborers' camps and guilds near where the gate will be in the great wall. This is usually a central location, and the workers will travel along the wall to reach their work site. You don't need to build a road for them along the length of the wall.

Tip for protecting your city against predator animals:
A predator loose in your city can wreak as much havoc as a mugger. Hunters and guards may save you from some predators, but towers, soldiers and some heroes are more effective.


IV. MULTIPLAYER
----------------

If you want to try the new multiplayer feature of EmperorRotMK, we highly recommend you start with the ahistorical "Eight Kingdoms" multiplayer scenario.  Although it is not a "tutorial," it was designed especially for first-time players, with relatively simple victory conditions for quick play.

Multiplayer game speed:
During a multiplayer game, you may find that the "Game speed" setting in the options menu will change throughout the course of the scenario.  This is due to the fact that the game tries to keep everyone close to the same game month.  Players who manage to get ahead of the others will find their game speed reduced, while those who are behind will be sped up.  This is normal. Furthermore, you cannot increase your game speed using the bracket hotkey during a multiplayer game.

Saved games for multiplayer play:
The multiplayer software saves a copy of each player's city periodically.  It also saves a copy of each player's city when the host clicks the "Save Game (All players)" button on the Players panel, which is opened through the File Menu. These save files are named <Player Name>_X.sav where x varies from 0 to 9.  If you want to restart from a save, the host should first determine (by file time) the most recent save that all players have present on their machine.  The host then loads that game in.  As each player connects, the software automatically finds the corresponding file on each player's machine to reestablish the game session.  If you have problems, we suggest the host try the previous save.  It may have been the case that one of the players was a month behind the others and did not get the most recent saved game.

Multiplayer connectivity issues:
For firewall or other multiplayer problems, please see the in-game help section of the multiplayer lobby.  You can find this on the "Help" tab once you have entered the lobby.

Trading with other players tip:
When trading with another player, both of you must have a staffed trade building for the respective city. You should agree through chat or private message what you are willing to trade, then set your trade building imports and exports accordingly. If you have inventory in a trade building that's not moving, or you are not receiving the good you want to buy, confer with the other player to discover what the bottleneck is. Your trade partner may not be nearly as adept as you at trading and could need some advice.

Chat history tip:
It is easy to miss a chat message during play when your attention is elsewhere or you spent a length of time on the empire map. Therefore, remember to periodically check your "Chat History" button on the messages dialog to see if you missed something important. Also, if you turned off multiplayer messages in the options menu, you'll certainly miss some important messages, so keep it turned on or check the messages dialog and chat history frequently.

Long multiplayer games and game slowdown:
Some of the multiplayer games may take a large amount of time to complete. Remember to have the host save the game for continuation later. Also, after extended periods of play, the game may slow slightly. If this occurs, the players should stop the session and reload from the last save. The game pace should then pick up.

Multiplayer lobby and screen resolution:
If your Windows desktop is set to 800 x 600 resolution, but you play Emperor at 1024x768, you may experience problems in the multiplayer lobby.  Specifically, if you go into the Multiplayer lobby and click a web link, and then returns to the lobby, the lobby size will be too large.  We recommend always setting your desktop resolution to 1024x768 or higher if you are going to play Emperor at the 1024x768 resolution.

MANUAL INFORMATION UPDATES
(1) On the Empire Map, if you have trouble selecting an Emissary, Spy or Army icon because it is too close to a city icon, press the Ctrl key while clicking on the figure icon and this should select it.
(2) If you have the hero Huang Di in your city, he satisfies any tribute payment of ceramics.
(3) If you have the hero Bodhidharma in your city, he satisfies any tribute payment of tea.
(4) The clock tower monument needs deliveries of stone, wood and steel during construction (the manual mistakenly says wood and bronze).
